### 1. 菜单结构重组

| 调整前 | 调整后 | 说明 |

| 资产详情 | - | 移除，建议通过资产管理子菜单进入 |
| 出库资产 | 资产出库 | 移动至资产管理子菜单，名称标准化 |
| 回收资产 | 资产回收 | 移动至资产管理子菜单，名称标准化 |
| 报废资产 | 资产报废 | 移动至资产管理子菜单，名称标准化 |

| 低值易耗 | - | 移除，功能合并至其他模块 |
| 部门管理 | 员工管理/部门管理 | 移动至员工信息子菜单 |
| 员工管理 | 员工管理/员工管理 | 移动至员工信息子菜单 |

### 2. 代码优化

- **删除未使用的图标导入**：`DeleteFilled`、`Document`、`DocumentAdd`、`DocumentRemove`、`Management`、`Refresh`、`Histogram`
- **清理冗余代码**：删除注释掉的旧版 `handleSelect` 函数实现
- **简化变量命名**：移除不必要的注释
- **保持语义化**：子菜单 index 使用语义化命名（`asset`、`employee`、`info`）

## 优化收益

1. **结构清晰**：按业务领域分组，用户更容易找到所需功能
2. **代码精简**：减少约 40% 的冗余代码，提升维护性
3. **命名规范**：统一使用"资产XX"、"员工XX"等标准化命名
4. **性能提升**：减少未使用的图标导入，降低打包体积

## 注意事项

- `低值易耗` 功能已移除，相关业务需确认是否需要保留或合并到其他模块
- `资产详情` 入口已移除，如需访问需通过资产管理子菜单或其他入口
