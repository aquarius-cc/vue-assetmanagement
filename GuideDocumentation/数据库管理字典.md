# 数据库管理字典

>
> **文档生成日期**：2026-05-08

## 一、资产管理模块（assetmanagement）

### 1.1 仓库管理（Storage）

| 属性 | 值 |
|------|-----|
| **模型名称** | Storage |
| **数据库表名** | am_storage |
| **verbose_name** | 仓库管理 |
| **功能说明** | 用于管理资产的存储仓库，包括新货仓库、回收仓库、待报废仓库等类型 |

#### 1.1.1 字段说明

| 字段名 | 数据库类型 | verbose_name | 约束条件 | help_text |
|--------|------------|--------------|----------|-----------|
| id | BigAutoField | ID | 主键，自动增长 | 记录唯一标识 |
| create_time | DateTimeField | 创建时间 | auto_now_add=True | 记录创建时间 |
| update_time | DateTimeField | 更新时间 | auto_now=True | 记录更新时间 |
| is_delete | BooleanField | 是否删除 | default=False | 软删除标记 |
| storage_code | CharField(20) | 仓库编码 | unique=True | 仓库唯一编码，用于业务关联 |
| storage_name | CharField(100) | 仓库名称 | unique=True | 仓库名称，用户可见的展示名称 |
| storage_address | CharField(200) | 仓库地址 | 可为空 | 仓库的物理地址 |
| storage_type | CharField(50) | 仓库类型 | choices，可为空 | 仓库类型：新货/回收/待报废 |
| storage_description | TextField | 仓库描述 | 可为空 | 仓库的补充说明信息 |

#### 1.1.2 choices 选项值

| 选项值 | 显示名称 |
|--------|----------|
| newasset | 新货仓库 |
| recycle | 回收仓库 |
| damaged | 待报废仓库 |

#### 1.1.3 索引信息

| 索引名称 | 索引字段 |
|----------|----------|
| storage_code | storage_code |
| storage_type | storage_type |

### 1.4 资产管理（Asset）

| 属性 | 值 |
|------|-----|
| **模型名称** | Asset |
| **数据库表名** | am_asset |
| **verbose_name** | 资产管理 |
| **功能说明** | 核心资产模型，管理资产从入库、领用、报废全生命周期。包含资产基本信息、状态跟踪、关联合同/仓库/人员等信息 |

#### 1.4.1 字段说明

| 字段名 | 数据库类型 | verbose_name | 约束条件 | help_text |
|--------|------------|--------------|----------|-----------|
| id | BigAutoField | ID | 主键，自动增长 | 记录唯一标识 |
| create_time | DateTimeField | 创建时间 | auto_now_add=True | 记录创建时间 |
| update_time | DateTimeField | 更新时间 | auto_now=True | 记录更新时间 |
| is_delete | BooleanField | 是否删除 | default=False | 软删除标记 |
| asset_recordcode | CharField(32) | 记录编码 | unique=True，db_index | 系统自动生成的入库记录编码 |
| asset_code | CharField(20) | 资产编码 | unique=True，editable=False | 资产唯一编码，不可修改 |
| asset_name | CharField(100) | 资产名称 | 必填 | 资产的名称 |
| asset_purchase_price | DecimalField(10,2) | 资产购买价格 | 必填 | 资产采购单价（元） |
| asset_purchase_number | IntegerField | 资产购买数量 | default=1 | 采购数量 |
| asset_unit | CharField(50) | 资产单位 | 可为空 | 计量单位：台/套/个等 |
| asset_brand | CharField(100) | 资产品牌 | 可为空 | 资产的品牌 |
| asset_specification | CharField(100) | 资产规格 | 可为空 | 资产的规格型号 |
| asset_type_code | ForeignKey | 资产类型 | 外键→AssetType | 关联的资产类型 |
| asset_contract_code | ForeignKey | 资产合同 | 外键→Contract，可为空 | 关联的采购合同 |
| asset_purchase_date | DateField | 资产购买日期 | 必填 | 资产采购的日期 |
| asset_warranty_period | IntegerField | 保修期（年） | 可为空 | 资产保修期限（年） |
| asset_entry_date | DateField | 入库日期 | 必填 | 资产入库的日期 |
| asset_storage_code | ForeignKey | 存储仓库 | 外键→Storage，可为空 | 资产当前所在仓库 |
| asset_using_location | CharField(100) | 资产使用地点 | 可为空 | 资产使用的地点 |
| asset_entry_person_jobcode | ForeignKey | 资产入库人工号 | 外键→Employee，可为空 | 办理入库的人员工号 |
| asset_applicant_jobcode | ForeignKey | 资产申请人工号 | 外键→Employee，可为空 | 资产申请人的工号 |
| asset_manager_jobcode | ForeignKey | 资产保管人 | 外键→Employee，可为空 | 资产保管人的工号 |
| asset_appearance | CharField(20) | 资产外观 | choices，可为空 | 资产外观状态 |
| asset_current_status | CharField(20) | 资产当前状态 | choices，default=in_store | 用于跟踪资产当前所处的流程阶段：在库/在用/报废 |
| using_record | TextField | 使用记录 | 可为空 | 资产使用历史记录 |
| asset_description | TextField | 资产描述 | 可为空 | 资产的补充说明 |

#### 1.4.2 外键关联关系

| 字段名 | 关联模型 | 关联字段 | on_delete | related_name |
|--------|----------|----------|-----------|--------------|
| asset_type_code | AssetType | asset_type_code | DO_NOTHING | assets |
| asset_contract_code | Contract | contract_code | SET_NULL | assets |
| asset_storage_code | Storage | storage_code | DO_NOTHING | assets |
| asset_entry_person_jobcode | Employee | employee_jobcode | SET_NULL | assets_entry |
| asset_applicant_jobcode | Employee | employee_jobcode | DO_NOTHING | assets_applicant |
| asset_manager_jobcode | Employee | employee_jobcode | DO_NOTHING | assets_manager |

#### 1.4.3 choices 选项值

**资产外观（asset_appearance）**

| 选项值 | 显示名称 |
|--------|----------|
| newly | 新增加资产 |
| used | 已使用资产 |
| damaged | 待报废资产 |
| waste | 已报废资产 |

**资产当前状态（asset_current_status）**

| 选项值 | 显示名称 |
|--------|----------|
| in_store | 在库资产 |
| in_use | 在用资产 |
| in_scrapped | 报废资产 |

#### 1.4.4 索引信息

| 索引名称 | 索引字段 |
|----------|----------|
| asset_recordcode | asset_recordcode |
| asset_code | asset_code |
| asset_current_status | asset_current_status |
| asset_type_code | asset_type_code |
| asset_storage_code | asset_storage_code |

#### 1.4.5 特殊功能

**自动生成记录编码规则**

创建记录时自动生成记录编码，格式为：`Entry + 年月日时分秒 + 8位UUID`

例如：`Entry20260508143025A1B2C3D4`

### 1.5 出库资产管理（OutAsset）

| 属性 | 值 |
|------|-----|
| **模型名称** | OutAsset |

| 字段名 | 数据库类型 | verbose_name | 约束条件 | help_text |

| is_delete | BooleanField | 是否删除 | default=False | 软删除标记 |

| outasset_applicant_jobcode | ForeignKey | 出库资产申请人 | 外键→Employee，可为空 | 资产申请人的工号 |

| return_date | DateField | 归还日期 | 可为空 | 借用资产的预计或实际归还日期 |
| outasset_using_location | CharField(200) | 出库资产使用地点 | 必填 | 资产使用的位置 |
| outasset_date | DateField | 出库日期 | auto_now_add=True | 资产出库的日期 |
| outasset_type | CharField(50) | 出库类型 | choices，可为空 | 出库类型：领用/借用 |
