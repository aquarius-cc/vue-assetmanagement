## 一、需求概述

### 1.1 功能需求
在通讯录管理页面的右侧内容区、人员列表区域新增一个筛选功能，可以按人员状态（在职/离职/退休）筛选人员列表。

### 1.2 用户选择
| 选项 | 选择 |
|------|------|
| 筛选方式 | 单选下拉框 |
| 筛选位置 | 卡片头部右侧 |
| 后端支持 | 后端已支持，需前端扩展 |

### 1.3 业务规则
- 筛选条件：`employee_status` 字段
- 可选值：`active`（在职）、`left`（离职）、`retirement`（退休）
- 默认值：空（显示全部）
- 筛选范围：当前选中部门下的人员

## 三、实施方案

### 3.1 第一步：扩展 API 类型定义

**文件**：`src/utils/Department.ts`

在 `DepartmentEmployeeListResponse` 后添加新的查询参数接口：

```typescript
/**
 * 部门员工列表查询参数
 * 用于按条件筛选部门下的人员
 */
export interface DepartmentEmployeeListQueryParams {
  /** 人员状态筛选（可选，不传则返回全部） */
  status?: 'active' | 'left' | 'retirement' | ''
  /** 索引签名：兼容 request.get 的 params 类型要求 */
  [key: string]: string | number | boolean | null | undefined
}
```

### 3.2 第二步：扩展 API 方法签名

**文件**：`src/api/department.ts`

修改 `getDepartmentEmployeeList` 方法，添加可选的查询参数：

```typescript
// 导入新增的类型
import type {
  // ... 现有导入
  DepartmentEmployeeListQueryParams,
} from '@/utils/Department'

// 修改方法签名
/**
 * 获取部门下的员工列表
 * 后端返回格式: { department: {...}, employees_count: number, employees: [...] }
 * @param department_code 部门编码
 * @param params 查询参数（可选：status 状态筛选）
 * @returns 员工列表响应对象
 */
getDepartmentEmployeeList: (
  department_code: string,
  params?: DepartmentEmployeeListQueryParams
): Promise<DepartmentEmployeeListResponse> => {
  return unwrapResponse(
    request.get<DepartmentEmployeeListResponse>(
      `/users/departments/${department_code}/employees/`,
      params
    )
  )
},
```

### 3.3 第三步：扩展 Store 层类型

**文件**：`src/stores/departmentStore.ts`

修改 `getDepartmentEmployees` 方法，添加 status 参数：

```typescript
// 导入新增的类型
import type {
  // ... 现有导入
  DepartmentEmployeeListQueryParams,
} from '@/utils/Department'

/**
 * 获取部门下的人员列表
 * 通过 Store 层封装 API 调用，统一数据访问入口
 * 后端返回格式: { department, employees_count, employees }
 *
 * @param departmentCode 部门编码
 * @param params 查询参数（可选：status 状态筛选）
 * @returns 员工列表（按 sort_order 升序）
 */
export const getDepartmentEmployees = async (
  departmentCode: string,
  params?: DepartmentEmployeeListQueryParams
): Promise<EmployeeExtended[]> => {
  const response: DepartmentEmployeeListResponse = await departmentAPI.getDepartmentEmployeeList(
    departmentCode,
    params
  )

  // 从响应中提取 employees 数组
  const list = response?.employees ?? []

  // 按 sort_order 升序排列，null 值排到最后
  return list.sort((a, b) => (a.sort_order ?? 999) - (b.sort_order ?? 999))
}
```

const filterStatus = ref<'' | EmployeeStatus>('')

const statusOptions = [

  { label: '离职', value: EmployeeStatus.LEFT },
  { label: '退休', value: EmployeeStatus.RETIREMENT },

const resetFilters = () => {

#### 3.4.3 修改 loadEmployeeList 方法

```typescript
// 修改 loadEmployeeList 方法，添加筛选参数

/**
 * 加载部门人员列表
 * 通过 Store 层获取数据（而非直接调用 API），统一数据访问入口
 * Store 层已处理排序和数组类型安全
 *
 * 特殊处理：根部门（isRoot=true）时，递归获取所有子部门的人员
 */
const loadEmployeeList = async () => {
  try {
    isLoading.value = true

    // 构建查询参数
    const queryParams: DepartmentEmployeeListQueryParams = {}
    if (filterStatus.value) {
      queryParams.status = filterStatus.value
    }

    if (props.isRoot && props.departmentTree.length > 0) {
      // 根部门：获取所有子部门的人员
      const allCodes = extractAllDepartmentCodes(props.departmentTree)
      // 并发获取所有部门人员
      const allEmployees = await Promise.all(
        allCodes.map((code) => getDepartmentEmployees(code, queryParams))
      )
      // 合并所有人员并去重（根据 employee_jobcode）
      const employeeMap = new Map<string, EmployeeExtended>()
      allEmployees.flat().forEach((emp) => {
        employeeMap.set(emp.employee_jobcode, emp)
      })
      employeeList.value = Array.from(employeeMap.values())
    } else {
      // 普通部门：仅获取当前部门人员
      employeeList.value = await getDepartmentEmployees(props.departmentCode, queryParams)
    }
  } catch (error) {
    console.error('加载人员列表失败:', error)
    ElMessage.error('加载人员列表失败')
  } finally {
    isLoading.value = false
  }
}
```

#### 3.4.5 添加筛选状态变化处理方法

```typescript
/**
 * 状态筛选变化处理
 * 切换筛选条件时，重新加载列表并重置分页
 */
const handleStatusFilterChange = () => {
  currentPage.value = 1
  loadEmployeeList()
}
```

#### 3.4.6 修改 watch 监听

修改现有的 watch，确保切换部门时重置筛选条件：

```typescript
// 部门编码、是否根部门、部门树变化时重新加载人员列表
watch(
  [() => props.departmentCode, () => props.isRoot, () => props.departmentTree],
  () => {
    // 重置筛选条件
    resetFilters()
    // 加载列表
    const treeNotEmpty = props.departmentTree && props.departmentTree.length > 0
    if (props.isRoot && treeNotEmpty) {
      loadEmployeeList()
    } else if (!props.isRoot) {
      loadEmployeeList()
    }
  },
  { immediate: true }
)
```

## 六、风险评估

### 6.1 已知风险

| 风险 | 级别 | 缓解措施 |
|------|------|----------|
| 后端 API 参数名不一致 | 低 | 提前与后端确认参数名 |
| 根部门筛选性能问题 | 中 | 确保后端有索引优化 |
| 筛选状态与列表不同步 | 低 | 筛选切换后立即刷新列表 |

### 6.2 回滚方案

如出现问题，可通过以下步骤回滚：
1. 移除 `DepartmentEmployeeList.vue` 中的筛选下拉框和相关逻辑
2. 恢复 `departmentStore.ts` 中 `getDepartmentEmployees` 方法签名
3. 恢复 `department.ts` 中 `getDepartmentEmployeeList` 方法签名
4. 移除 `Department.ts` 中新增的类型定义
